配置流程

把机场订阅真正用起来，关键不在口号，而在导入与分流。请按下列顺序操作，每一步完成后进入下一步。

第一步：选择套餐并完成订阅

对照设备数量和月流量挑选基础版、旗舰版或团队版。需要流媒体原生解锁或游戏专线时优先旗舰版；多人共用出口选团队版。年付可降低月均成本。订阅完成后进入用户中心。

第二步：复制订阅链接

在用户中心找到订阅地址，通常可一键复制 Clash、通用或单独协议格式。不要把链接发到公开群组。若更新节点失败，先检查链接是否被截断空格，再重新复制。

第三步：安装对应客户端

电脑优先使用桌面客户端，手机使用系统允许的应用或配置描述。也可使用 Clash 系、Surge、Quantumult 等常见第三方客户端。安装包请仅从本页「客户端下载」指引获取，避免来路不明的改包。

第四步：导入订阅并更新节点

打开客户端，选择「从 URL 导入」或「订阅管理」，粘贴链接并更新。成功后应看到香港、东京、新加坡、洛杉矶、伦敦等分组。若列表为空，切换网络后重试，或核对套餐是否仍在有效期。

第五步：选择节点、开启分流并验证

按延迟排序选择节点，办公可固定一条稳定线路，流媒体选择对应地区，游戏走 IPLC 分组。建议开启规则分流：国内域名直连，跨境流量走代理。用浏览器打开目标站点，再测一次延迟，确认没有全局误伤网银或内网。

常见问题

私人云是什么？和普通 VPN 加速器有何不同？

私人云是提供机场订阅的官方网络加速服务：你购买的是可更新的节点列表与流量配额，而不是单一固定服务器。通过 Clash 等客户端导入后，可按延迟和用途切换香港、日本、美国等出口，并配合分流规则使用。它强调套餐透明、配置步骤可跟做，以及旗舰版的原生流媒体与 IPLC 游戏优化。

如何完成从订阅到联网的配置流程？

顺序是：选套餐并支付 → 在用户中心复制订阅链接 → 下载对应系统客户端 → 粘贴链接更新节点 → 选择低延迟节点并打开规则分流。详细分解见本页「配置流程」五步。手机与电脑可共用同一订阅，但请控制在套餐允许的同时在线设备数内。

基础版、旗舰版、团队版该怎么选？

轻度网页与资料查阅选基础版（100GB / 3 台设备 / 基础流媒体）。需要稳定看片、游戏专线或优先工单选旗舰版（300GB / 5 台设备 / 全节点原生解锁 / IPLC）。公司或工作室多设备、要定制路由和专属对接选团队版（1000GB / 20 台设备 / VIP 带宽）。年付三档均为十个月价格。

客户端下载后导入失败或看不到节点怎么办？

先确认链接完整、套餐未过期，再在客户端里手动点一次更新。仍失败可更换网络后重试，或改用通用订阅格式。系统若拦截了 VPN 权限，需在设置中允许。本页「客户端下载」按系统列出了导入要点，无需寻找站外安装包。

流量如何计算？用尽后能否继续当梯子使用？

套餐按自然月计入极速流量，加密传输的实际出站字节会计入额度。用尽后将无法再走加速节点，需要等待下月重置或升级套餐。观看高清流媒体和下载会明显快于纯网页，建议在客户端查看用量，避免后台自动更新占用配额。

能否用于流媒体解锁和游戏加速？

基础版提供基础流媒体解锁，遇到严格地区检测时可能不够。旗舰版与团队版标注全节点原生解锁，并在旗舰版加入 IPLC 专线游戏加速优化。实际效果仍与时段、目标平台策略有关：先换同区域节点，再检查客户端是否全局代理导致 DNS 污染。
